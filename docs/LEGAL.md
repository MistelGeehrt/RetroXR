# Cadre juridique et règles du projet

Ceci n'est pas un avis juridique. Ce sont les faits connus en octobre 2026 et les règles que RetroXR s'impose.

## Sur quoi on s'appuie

- Les **décompilations** (Super Mario 64, Zelda OoT…) et les **ports PC** Harbour Masters existent publiquement sur GitHub depuis 2020-2022. Leur règle de survie : **aucun asset, aucune ROM, aucune clé dans le dépôt** ; l'utilisateur fournit sa propre ROM, dont le programme extrait les données localement. Nintendo a fait retirer des émulateurs Switch (2026, argument du contournement des clés de chiffrement) et des binaires de ports, mais pas ces dépôts de code.
- Les mods VR gratuits (UEVR, ports VR de RaYRoD) ne sont pas visés. Les retraits DMCA récents dans le modding VR (Take-Two 2022, CD Projekt et 505 Games 2026) visaient tous des mods **payants**.

## Règles de RetroXR

1. **Aucune ROM, aucun asset, aucune clé, aucun binaire de jeu** dans le dépôt ni dans les releases. Les exécutables publiés ne contiennent que du code ; ils réclament la ROM de l'utilisateur au premier lancement.
2. **Aucune monétisation de l'accès.** Dons possibles, jamais de paywall ni de palier donnant accès au code ou aux builds.
3. **Pas de distribution de ROM, pas de lien vers des ROM**, pas d'aide pour en obtenir. La documentation suppose que l'utilisateur possède la cartouche et sait la lire.
4. Code original sous MIT ; les projets d'origine gardent leur licence (libultraship, Ghostship : MIT). **Rien n'est copié des projets GPL** (MVRH/RaYRoD), incompatibles avec le MIT.
5. Mention claire : RetroXR n'est affilié ni à Nintendo, ni à Meta, ni à Harbour Masters.
6. En cas de demande de retrait : retirer l'élément visé, documenter publiquement, ne pas contester seul.
